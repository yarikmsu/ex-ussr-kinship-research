# Дополнения форка

Форк дополняет навык уроками из исследований его владельца. Основной текст навыка (`SKILL.md`, `references/*.md`) совпадает с каноническим репозиторием — кроме раздела «Дополнения форка» в `SKILL.md`. Дополнения лежат в этой папке, кейсы — в `evals/fork-lessons.yaml`. Поэтому слияние обновлений почти не даёт конфликтов.

## Как читать

- `references/fork/<имя>.md` дополняет одноимённый `references/<имя>.md`. Заголовки разделов повторяют заголовки основного файла с пометкой «— дополнения форка».
- `techniques.md` (если есть) — технические приёмы работы с браузером, просмотрщиками и сервисами.
- `evals/fork-lessons.yaml` — кейсы для содержательной проверки дополнений. Это не автоматические тесты.

## Приоритет

Правила форка определяет его владелец. При расхождении с основным текстом действует текст форка.

## Публичность

Репозиторий публичный. Примеры обобщены: в них нет имён, мест, дат и идентификаторов конкретных дел. Материалы дел хранятся вне этой рабочей копии.

## Обновление из канонического репозитория

Здесь `origin` — канонический репозиторий, `fork` — этот форк; проверьте `git remote -v`.

```bash
git fetch origin && git fetch fork
git switch main
git merge --ff-only fork/main
git merge origin/main
python3 -m unittest discover -s tests
git push fork main
```

Ветку форка не перезаписывать: без `--force` и без `gh repo sync --force`.

## Перенос в канонический репозиторий

Отдельные дополнения предлагаются в канонический репозиторий отдельными PR — в обобщённой форме и по его правилам. Если принятый текст полностью покрывает дополнение, дополнение отсюда удаляется. Если дополнение остаётся сильнее, его сохраняют.
