# Беседа о семейной истории — дополнения форка

## Письменные анкеты — дополнения форка (новый раздел)

- **Перед новой анкетой ищите по дословным записям прежних ответов** (тексты артефактов и дословные записи в плане дела), а не только по реестрам.
  - Отдельно ищите фразы-закрытия вроде «больше ничего не знает»: они снимают вопросы о том, о чём сказаны (например, обо всём, что касается этого человека), а не только тот вопрос, на который так ответили (`references/fork/field-lessons.md`, раздел 6). Новый вопрос на ту же тему задавайте, только если документы дали новое основание, например найденное имя для проверки без подсказки.
  - Неясный короткий ответ уточняйте отдельным вопросом, а не повтором прежнего (уже сказанное из списка убирайте — пункт о мессенджере ниже).
  - Пропущенные вопросы прошлой анкеты переносите в новую с пометкой, что их уже задавали. Если адресат обошёл вопрос намеренно или тема чувствительная (репрессии, усыновление, болезни), повторяйте его только по решению пользователя.
- **В устной беседе подсказку давайте только после открытого ответа.** Фиксируйте в деле, какие подсказки уже прозвучали.
- **В мессенджере подсказку «на потом» не придержать: адресат читает весь список сразу.**
  - В рассылаемом тексте подсказок нет вовсе. Несколько гипотез сворачиваются в один открытый вопрос: «Были ли у мамы братья и сёстры?», а не «был ли брат такой-то такого-то года?».
  - Ключи для сверки ответов хранятся в плане дела, а не в тексте для семьи.
  - Уточнение с подсказкой допустимо только отдельным сообщением после открытого ответа. Такой ответ помечайте как «ответ на подсказку».
  - Уже сказанное адресатом из списка убирайте: короткий список заполняют охотнее. Документированный факт оставляйте, только если слепое совпадение что-то добавит.
  - Называйте родню так, как её называет адресат («ваш папа»), а не по имени из древа.
- **Вопрос проверяет гипотезу по документам.**
  - Спрашивайте об именах, датах и местах, которые уже найдены, но семье ещё не названы.
  - Об уже документированных фактах тоже можно спрашивать, не называя их: совпадение без подсказки даёт независимое подтверждение. Совпадение отметьте в `reliability_notes` как сведение о канале. Статус и `confidence` других утверждений оно не меняет: каждое оценивайте по своему происхождению.
  - Заранее запишите в плане решающий признак, например: «если назовёт бабушку Ольгой Петровной, отец из трёх кандидатов почти определён».
- **О собственном предположении родственника** («думаю, он родился там-то») спрашивайте: «вы это слышали или так рассуждаете?». Ключи, которые могли бы подсказать ответ, в анкету не включайте.
- **Если анкету зачитывают по телефону,** в начале укажите порядок важности вопросов: за один звонок всё обычно не успевают.
- **Если респондент запутался, на что уже ответил,** дайте ему таблицу «отвечено / частично / нет» и короткий список только из оставшихся вопросов. Вопросы, на которые ответил другой родственник, из чужих анкет уберите.
- **Если ответа не ждать скоро,** поделите вопросы на две группы. На одни ответит только память (имя мужа, о каких «проблемах» говорили в семье, кладбище). Другие может закрыть документ (год рождения, место службы, состав семьи) — их перенесите в план поиска.
