# Браузер, динамические сайты и CAPTCHA — дополнения форка

## 6. Географические ограничения — дополнения форка

- **Заблокированный из сети пользователя сайт** передайте пользователю списком: официальные адреса, строки поиска, найденные контакты с пометкой «не подтверждено». Пользователь может открыть их сам, в том числе через VPN.

## 7. Rate limit и блокировка — дополнения форка

- **FamilySearch перестал отдавать снимки или выдачу — сначала проверьте вход, потом решайте о паузе.** Условие: снимки не показываются в просмотрщике, предзагрузка получает отказ (`onerror`) или поиск отвечает ошибкой.
  - Остановите загрузку и поиск, переключитесь на разбор и запись. Ограничение не обходите.
  - Сделайте один диагностический запрос метаданных тома (путевые метки) из вкладки FamilySearch, как в `references/fork/techniques.md`, «FamilySearch», с `cache: 'no-store'`. Это не повтор загрузки: основной раздел 7 требует до следующих шагов оценить фактический ответ.
  - 401 или страница входа вместо JSON — истекла сессия входа: попросите пользователя войти заново (основной раздел «5а. Вход в аккаунт»; входит он сам). Пауза не поможет. По наблюдению владельца форка 13.11.2026, так выглядел внезапный отказ всех кадров, включая только что открытые.
  - Любой другой ответ — пауза 30–60 минут. В журнал запишите код и вывод как неподтверждённый: при JSON с кодом 200 и отказе снимков — «вероятно, лимит частоты», иначе — «причина не установлена».
  - Если запрос собрать нечем (том открыт не по путевой метке) или отказ повторился после паузы, попросите пользователя проверить вход и запишите маршрут как `blocked` с точкой возврата (основной раздел 8).
- **Сервер изображений FamilySearch ограничивает частоту.**
  - По наблюдению владельца форка 09.11.2026, после примерно 1400 загрузок снимков за 20 минут (в другой раз — уже после примерно 300) новые снимки перестали отдаваться: и через API, и в обычном просмотрщике («Не удаётся отобразить снимок»). API метаданных при этом отвечал 200.
  - Предзагружайте снимки порциями по 200–300, с паузами.
- **Быстрые веб-проверки** (справочники номеров частей, каталоги архивов, справочники административного деления) планируйте отдельным пунктом «в паузах FamilySearch». Тогда они не отнимают время у главной линии и не теряются в конце очереди.
