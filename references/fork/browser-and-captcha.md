# Браузер, динамические сайты и CAPTCHA — дополнения форка

## 6. Географические ограничения — дополнения форка

- **Заблокированный из сети пользователя сайт** передайте пользователю списком: официальные адреса, строки поиска, найденные контакты с пометкой «не подтверждено». Пользователь может открыть их сам, в том числе через VPN.

## 7. Rate limit и блокировка — дополнения форка

- **Сервер изображений FamilySearch ограничивает частоту.**
  - По наблюдению владельца форка 09.11.2026, после примерно 1400 загрузок снимков за 20 минут (в другой раз — уже после примерно 300) новые снимки перестали отдаваться: и через API, и в обычном просмотрщике («Не удаётся отобразить снимок»). API метаданных при этом отвечал 200.
  - Предзагружайте снимки порциями по 200–300, с паузами.
  - При отказе остановите загрузку, переключитесь на разбор и запись и сделайте паузу на 30–60 минут. Ограничение не обходите.
- **Быстрые веб-проверки** (справочники номеров частей, каталоги архивов, справочники административного деления) планируйте отдельным пунктом «в паузах FamilySearch». Тогда они не отнимают время у главной линии и не теряются в конце очереди.
