# Стартовый каталог источников — дополнения форка

## Репрессии, коллективизация, беженцы — дополнения форка

- **«Открытый список».**
  - `api.php` быстро отвечает 429. После первого 429 прекратите запросы к нему; обычные страницы и `Служебная:OlSearch` в том же клиенте работают — открывайте их по одной, с паузами.
  - Поле `olsearch-categories` (региональная «Книга памяти», регион) даёт региональный срез фамилии за один запрос; `birth_min`, `birth_max` и `page=N` тоже работают.
  - Список всех формуляров фамилии даёт `list=allpages&apprefix=<Фамилия>`; при первом 429 остановитесь.
- **«Бессмертный барак».** Поиск идёт через POST на «/» (`post_name=search`, `query`, `section=books|stories`, `page`). Выдача нечёткая (ИЛИ), точные совпадения стоят первыми. Не все тома региональных книг памяти есть на сайте — проверяйте, какие доступны (сопоставление районов с томами — `references/fork/field-lessons.md`, раздел 3).
